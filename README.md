# OTDR Batch Report

Εφαρμογή για Windows 10/11 που ανοίγει **χιλιάδες** μετρήσεις OTDR (`.sor`),
αντιστοιχίζει αυτόματα τις μετρήσεις **1310 nm** με τις **1550 nm** της ίδιας ίνας
και βγάζει **μαζικά PDF αναφορές** (ένα PDF ανά καλώδιο, μία σελίδα ανά ίνα).

Αντικαθιστά την παλιά εφαρμογή `OTDR.exe` (v2.2.8) που είχε όριο 8 αρχεία και δεν
μπορούσε να βάλει 1310 και 1550 στο ίδιο PDF.

## Τι κάνει

- **Χωρίς όριο αρχείων**: άνοιγμα ολόκληρου φακέλου (και υποφακέλων) ή drag & drop.
  Δοκιμασμένο με 2.000+ αρχεία (φορτώνουν σε ~1–2 δευτερόλεπτα).
- **Αντιστοίχιση από το όνομα αρχείου**:

  | Αρχείο                            | Καλώδιο           | λ    | Ίνα  |
  |-----------------------------------|-------------------|------|------|
  | `FARM1.R01_SCP31_1310_0117.sor`   | `FARM1.R01_SCP31` | 1310 | 0117 |
  | `FARM1.R01_SCP31_1550_0117.sor`   | `FARM1.R01_SCP31` | 1550 | 0117 |
  | `FARM1.R01_SCP31_0117_1550.sor`   | `FARM1.R01_SCP31` | 1550 | 0117 |
  | `FARM1.R01_SCP31_0117.sor`        | `FARM1.R01_SCP31` | από το αρχείο | 0117 |

  Τα διαχωριστικά μπορεί να είναι `_`, `-`, `.` ή κενό. Αν το όνομα δεν έχει μήκος κύματος,
  διαβάζεται από το ίδιο το `.sor`.
- **Έλεγχος πληρότητας**: δείχνει ποιες ίνες δεν έχουν και τα δύο μήκη κύματος
  (π.χ. λείπει το 1550 της ίνας 12) και τα διπλότυπα.
- **Μαζικό PDF**: επιλογή καλωδίων και εύρους ινών (π.χ. 0001 έως 0300).
  - Σελίδα σύνοψης καλωδίου: μήκος, απώλεια, dB/km και PASS/FAIL ανά ίνα και μήκος κύματος.
  - Μία σελίδα ανά ίνα: στοιχεία μέτρησης, γράφημα **1310 + 1550 μαζί** (ή ξεχωριστά),
    πίνακες συμβάντων για κάθε μήκος κύματος.
  - Ένα PDF ανά καλώδιο (`FARM1.R01_SCP31_0001-0300.pdf`) ή ένα PDF για όλα.
  - Ελληνικά ή Αγγλικά, με στοιχεία εταιρείας, λογότυπο, πελάτη, έργο και τεχνικό
    (ό,τι συμπληρώσεις στις ρυθμίσεις, αλλιώς τίποτα).
- **Κριτήρια Pass/Fail** που ρυθμίζονται: απώλεια κόλλησης, απώλεια connector, ανάκλαση,
  εξασθένηση ανά μήκος κύματος, συνολική απώλεια.
- **Προβολή** καμπυλών με zoom (ροδέλα ποντικιού) και πίνακα συμβάντων.

## Εγκατάσταση

1. Στο GitHub, άνοιξε **Actions → Build Windows installer → την τελευταία επιτυχημένη εκτέλεση**
   και κατέβασε το `OTDRBatchReport-Setup-x.y.z` από τα *Artifacts*.
   Αν έχει γίνει έκδοση με tag `v*`, το Setup βρίσκεται και στα **Releases**.
2. Τρέξε το `OTDRBatchReport-Setup-x.y.z.exe`. Αν εμφανιστεί το SmartScreen
   («Τα Windows προστάτευσαν τον υπολογιστή σας»), πάτα **Περισσότερες πληροφορίες → Εκτέλεση
   οπωσδήποτε**. Αυτό συμβαίνει επειδή το πρόγραμμα δεν έχει ψηφιακή υπογραφή.
3. Το πρόγραμμα εμφανίζεται στο μενού Έναρξη ως **OTDR Batch Report**.

## Χρήση

1. **Άνοιγμα φακέλου** → διάλεξε τον φάκελο με τα `.sor` (ή σύρε τον στο παράθυρο).
2. Αριστερά βλέπεις τα καλώδια (ίνες, ελλιπείς, FAIL). Στη μέση τις ίνες με 1310/1550
   δίπλα-δίπλα. Κάτω το γράφημα και τα συμβάντα της επιλεγμένης ίνας.
3. **Ρυθμίσεις αναφοράς** → στοιχεία εταιρείας/πελάτη, γλώσσα, κριτήρια Pass/Fail.
4. **Δημιουργία PDF** → καλώδια, εύρος ινών, φάκελος εξόδου → *Δημιουργία*.
   Μπορείς να το ακυρώσεις οποιαδήποτε στιγμή.

## Τι κρατήθηκε από την παλιά εφαρμογή

Η ανάγνωση των `.sor` ακολουθεί τον παλιό κώδικα της Grandway
(`SORPC_grandway/SorAssist.cpp`), ώστε οι αποστάσεις και τα dB να ταιριάζουν
με την παλιά εφαρμογή:

- θέση συμβάντος = `time_of_travel × 10⁻¹⁰ × c / n`
- απόσταση ανά σημείο = `data_spacing × 10⁻¹⁴ × c / n`
- τιμή καμπύλης = `raw × scale / 10⁶` dB

Οι στήλες του πίνακα συμβάντων είναι οι ίδιες με της παλιάς λίστας (Απόσταση, Απώλεια,
Ανάκλαση, Εξασθένηση, Αθροιστική απώλεια, Pass/Fail). Υποστηρίζονται τα SOR
Telcordia SR-4731 έκδοσης 1 και 2, από Grandway και από άλλους κατασκευαστές.

## Για προγραμματιστές

```bash
pip install -r requirements-dev.txt
python -m otdr_report                         # εκκίνηση εφαρμογής
pytest                                        # tests
python -m otdr_report.synthetic out --fibers 300   # δοκιμαστικά .sor
```

Build σε Windows:

```bat
pyinstaller --noconfirm OTDRBatchReport.spec
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" /DAppVersion=1.0.0 installer\setup.iss
```

Το workflow `.github/workflows/build-windows.yml` τα κάνει αυτόματα σε κάθε push:
τρέχει τα tests, φτιάχνει το exe, ελέγχει το exe με `--selftest` και βγάζει το Setup.
Για νέα έκδοση: άλλαξε το `otdr_report/__version__` και κάνε push ένα tag, π.χ. `v1.0.1`.

### Δομή

| Αρχείο | Περιεχόμενο |
|---|---|
| `otdr_report/sor.py` | Αναγνώστης `.sor` (SR-4731 v1/v2) |
| `otdr_report/matching.py` | Ανάλυση ονομάτων, ομαδοποίηση καλώδιο → ίνα → λ |
| `otdr_report/settings.py` | Ρυθμίσεις αναφοράς και κριτήρια Pass/Fail |
| `otdr_report/pdf_report.py` | Δημιουργία PDF (reportlab) |
| `otdr_report/app.py` | Παράθυρο εφαρμογής (PySide6 + pyqtgraph) |
| `otdr_report/synthetic.py` | Γεννήτρια δοκιμαστικών `.sor` |
| `installer/setup.iss` | Πρόγραμμα εγκατάστασης (Inno Setup) |

Γραμματοσειρές: DejaVu Sans (ελεύθερη άδεια, `otdr_report/fonts/LICENSE-DejaVu.txt`).
